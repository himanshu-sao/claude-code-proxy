## Whole-job notes for the integration reviewer
- No test drives a mid-stream failure through `endpoints.py` end to end. That path is `create_message` -> `_await_first_chunk` / `_prepend` -> the converter -> `StreamingResponse`. Slice C's tests cover errors before the first chunk, and slice D's tests drive the converter alone.
